  <h2>📖 About</h2>
  <p>
    Daleeli is a travel discovery app for tourist places in Egypt. Instead of just showing
    polished photos and star ratings, every place gets an <strong>Honest Truth</strong> card —
    generated by AI from real visitor reviews — surfacing genuine strengths and practical
    warnings (like "expect baksheesh requests here" or "closes earlier than listed") instead of
    brochure copy.
  </p>

  <h2>✨ Features</h2>

  <div class="feature-card">
    <h4>Explore Real Places <span class="ai-tag" style="background:var(--olive);">DATA</span></h4>
    <p>Browse curated tourist places as postcard-style cards, with search and filters by governorate and category.</p>
  </div>

  <div class="feature-card">
    <h4>Honest Truth <span class="ai-tag">AI</span></h4>
    <p>Gemini analyzes real visitor review text for each place and generates an honest summary plus a list of practical warnings — displayed like a handwritten note.</p>
  </div>

  <div class="feature-card">
    <h4>Suggested Itineraries <span class="ai-tag">AI</span></h4>
    <p>Gemini composes multi-day trip plans from the places already in the app's dataset, grouped by region and duration.</p>
  </div>

  <div class="feature-card">
    <h4>Share Your Experience</h4>
    <p>Users can post a photo and short comment about a place they've visited, shown in a "Recent Experiences" feed on Home.</p>
  </div>

  <div class="feature-card">
    <h4>My Trips</h4>
    <p>Save places and revisit AI-suggested itineraries in one place.</p>
  </div>

  <h2>🏗 Architecture</h2>
  <p>The project follows Clean Architecture, split into three layers:</p>
  <pre><code>lib/
  data/            # data sources, models, repository implementations
  domain/          # entities, repository interfaces, use cases
  presentation/    # screens, widgets, cubits</code></pre>

  <h2>🚀 Getting Started</h2>
  <h3>1. Clone the project</h3>
  <pre><code>git clone https://github.com/your-username/daleeli.git
cd daleeli</code></pre>

  <h3>2. Install dependencies</h3>
  <pre><code>flutter pub get</code></pre>

  <h3>3. Set up environment variables</h3>
  <p>Create a <code>.env</code> file in the project root with your Gemini API key:</p>
  <pre><code>GEMINI_API_KEY=your_key_here</code></pre>

  <h3>4. Set up Firebase</h3>
  <ul>
    <li>Create a Firebase project at <code>console.firebase.google.com</code></li>
    <li>Enable Authentication (Email + Google) and Firestore</li>
    <li>Add your <code>google-services.json</code> (Android) / <code>GoogleService-Info.plist</code> (iOS)</li>
  </ul>

  <h3>5. Run the app</h3>
  <pre><code>flutter run</code></pre>

  <h2>📂 Seed Data</h2>
  <p>
    Initial place data (name, photo, category, governorate, reviews) lives in
    to Firestore on first run.
  </p>
